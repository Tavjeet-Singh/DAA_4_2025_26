How It Works

01 /

Frequency Analysis

Scans the input and counts how often each character appears.

02 /

Build Tree

Constructs a min-heap priority queue to grow a binary tree bottom-up.

03 /

Encode & Decode

Common chars get short codes; rare chars get longer ones. Header stores the table for exact reconstruction.

CLI Usage (after building)
# Build
make

# Compress
./huffman compress input.txt output.huf

# Decompress
./huffman decompress output.huf restored.txt
Windows Build
g++ -std=c++17 -O2 -o huffman.exe src/huffman.cpp
